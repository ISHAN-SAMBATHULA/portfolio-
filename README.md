# Ishan Sambathula - Portfolio

Awwwards-level 3D portfolio featuring "The Neural Core" WebGL experience, built with React, Three.js, and Framer Motion.

## Requirements
- Node.js 18+

## Quick Start (Local Development)

1. **Install dependencies**
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Start the development server**
   ```bash
   npm run dev
   ```

## Production Build

To create an optimized production build:
```bash
npm run build
```
This generates a `dist` folder ready for deployment.

## Deploying to Vercel

1. Push this repository to your GitHub account.
2. Log into [Vercel](https://vercel.com) and click **Add New > Project**.
3. Import your GitHub repository.
4. Vercel will automatically detect Vite. Leave the default settings:
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Click **Deploy**.
